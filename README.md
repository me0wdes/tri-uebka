# Три уёбка — одна клавиатура

Скилл для Claude Code и других агентов: хаос-тестирование программы через её клиент.

Агент тестирует за трёх персонажей сразу:

- **бешеная обезьяна** жмёт не туда, передумывает посреди действия и сохраняет пустое;
- **саботажник** ищет цепочку разрешённых действий, после которой данные портятся;
- **инженер с консолью** смотрит Console и Network, снимает клиентские ограничения, рвёт сеть и гоняет конкурирующие запросы.

Ничего не исправляется. Каждая находка сразу пишется в `CHAOS_TEST_JOURNAL.md`: шаги, точные данные, ожидаемое и фактическое, воспроизводимость, доказательства.

## Установка

Claude Code, как плагин:

```
/plugin marketplace add me0wdes/tri-uebka
/plugin install tri-uebka@tri-uebka
```

Через [skills CLI](https://github.com/vercel-labs/skills), для Claude Code, Codex, Cursor и других:

```bash
npx skills add me0wdes/tri-uebka
```

Вручную: скопировать `skills/tri-uebka` в `~/.claude/skills/`.

## Запуск

`/tri-uebka` или «устрой хаос-тест вот этому: <адрес тестового стенда>».

Гонять только на тестовом контуре и тестовых данных. БД, серверная консоль и правка исходников протоколом запрещены.
